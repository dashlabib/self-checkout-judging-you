A single funny remark from a judgmental self-checkout machine: twelve yoghurts, no spoon, no plan — and a loyalty card that has given up on its shopper. `main.py` (Python standard library only, deterministic) writes the line to `/output/entry.txt` for make.fun's "The Self-Checkout Is Judging You" bounty.

## Run it

```sh
python3 main.py
```
